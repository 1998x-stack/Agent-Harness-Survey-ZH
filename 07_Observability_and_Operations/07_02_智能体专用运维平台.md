# 07.02 智能体专用运维平台

通用追踪平台通常以 LLM 调用、工具调用和检索步骤作为 span 级事件。智能体专用平台增加了捕获**智能体级关注点**的抽象层。

## 核心抽象升级

| 通用平台 | 智能体专用平台 |
|---------|-------------|
| LLM 调用 | 会话生命周期 |
| 工具调用 | 智能体身份和角色管理 |
| 检索步骤 | 工具选择策略 |
| — | 跨会话状态交接 |

## 代表平台

| 平台 | 特色 |
|------|------|
| **AgentOps SDK** | 层级 span 模型，围绕智能体生命周期组织会话、智能体、操作/任务、工作流、工具调用和 LLM 调用 |
| **RagaAI Catalyst** | 面向 RAG 和多智能体工作负载，质量和安全仪表盘突出检索级和智能体级异常 |
| **Laminar** | 开源优先，组合追踪、评估和提示管理 |

## 学术形式化

### AgentOps 六阶段自动化管线

Moshkovich & Zeltyn（2025）提出：

```
观察 → 收集指标 → 检测异常 → 根因分析 → 推荐修复 → 自动化修复
```

进一步将利益相关者空间分解为四个角色：开发者、测试者、SRE、业务用户。

### 任务流发现

Moshkovich et al.（2025）通过用户研究证明：**79% 的实践者将非确定性执行流识别为智能体系统中最重大的挑战。**

### NLAH 框架

NLAH（Pan et al., 2026）将执行环境本身视为一级研究对象，通过系统消融实验量化各个执行环境模块——工具注册表、权限系统、钩子、技能、上下文折叠——对下游智能体性能的贡献。

> 对可观测性的启示：**执行环境不仅是监控的对象，还是干预的来源**——每个被消融的模块都是可观测性管线可以标记和调优的旋钮。

## 认知可观测性

认知可观测性将智能体级监控扩展到不仅问智能体**做了什么**，还问**为什么**。

**Watson**（Rombaut et al., 2025）部署"代理智能体"通过提示归因重现主智能体的输出并生成逐步推理追踪。在 MMLU 和 SWE-bench-lite 上的评估表明，恢复的推理追踪对手动调试和自动纠错都有效。

**AgentLens**（Lu et al., 2024）提供三窗格可视分析系统：大纲视图（轨迹）、智能体视图（带因果弧的事件栈）、监控视图（同步环境重放）。14 人用户研究表明在复杂分析任务上相较纯重放基线有显著改进。
