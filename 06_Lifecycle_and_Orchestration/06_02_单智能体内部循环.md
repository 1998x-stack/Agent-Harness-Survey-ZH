# 06.02 单智能体内部循环

单智能体内部循环是智能体系统中最基本的执行单元。单个智能体通过工具使用和反馈与环境反复交互，无需多个智能体之间的显式协调。这一抽象是交互式编码、调试和问题解决的基础。

## ReAct 范式

概念上，单智能体循环遵循 **ReAct 范式**（Yao et al., 2023），将**推理、行动和观察交替交织**。

正如 OpenAI 对 Codex 智能体循环的分析所强调的（OpenAI, 2026b），此类系统的行为**不仅由模型决定，还由构建提示、调用工具、管理控制流并将工具输出反馈到后续步骤的执行环境决定**。

## 执行模型分歧

在这一层级，主要的执行区别在于**无状态重放**与**混合执行**之间：

- **Codex CLI** 是**基于重放执行的最清晰示例**
- 实际编码智能体通常将**可重放历史与持久化工件**（文件、仓库、会话状态）结合

## 长周期执行的局限

尽管单智能体循环具有灵活性，但在长周期执行中会出现：

- **上下文碎片化**（context fragmentation）
- **累积错误**（accumulated errors）
- **薄弱的分解结构**（weak decomposition structure）

（Anthropic, 2025d）

这些局限正是驱动向更结构化的多智能体编排（§6.3）和完整生命周期管线（§6.4）演进的动力。
