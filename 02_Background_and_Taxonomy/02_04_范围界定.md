# 02.04 范围界定

我们使用**智能体执行环境（agent harness）**的狭义定义，而非"围绕 LLM 的任何软件"：

> 执行环境是将模型调用转化为**有界、有状态、工具中介的任务执行**的工程化包装器，通过执行基板、工具接口、上下文控制、编排调度、可观测性、评估反馈和治理约束来实现（OpenAI, 2026a; Anthropic, 2025d; LangChain, 2026b）。

因此，分析的基本单元是**使长周期智能体行为变得可控、可审查和可恢复的基础设施**，而非基础模型或提示本身。

## 纳入与排除的边界

我们按**功能**而非产品类别划定边界：

### ✅ 纳入范围

当智能体框架暴露以下可复用机制时，属于本综述的范围：
- 有状态编排
- 工具路由
- 运行时策略钩子
- 追踪捕获

### ❌ 排除范围

以下内容不属于本综述的范围（除非其被显式适配为智能体执行、状态管理、评估或工具使用的治理用途）：
- 薄模型 API 包装器
- 提示库
- 静态数据集
- 通用容器运行时
- 向量数据库
- APM 仪表盘
- 内容过滤器
