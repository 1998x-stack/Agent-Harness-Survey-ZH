# 02.08 语料库的局限性

本语料库应被解读为**可见智能体执行环境生态系统的地图**，而非对所有已部署智能体基础设施的普查。以下几类偏差需要注意：

## 偏差来源

| 偏差类型 | 具体表现 |
|---------|---------|
| **语言偏差** | 偏向英文来源的项目 |
| **可见性偏差** | 偏向 GitHub 可见的项目 |
| **开源性偏差** | 偏向开源工件 |
| **文档偏差** | 偏向维护者发布了足够实现细节以供外部编码的项目 |

## 代表性不足的类别

- **商业生产系统**：除非其工程博客、文档或 SDK 暴露了相关机制，否则代表性不足
- **非编码智能体基础设施**：编码智能体（coding agent）基础设施因拥有异常丰富的公开痕迹（仓库、基准、沙箱、issue-to-PR 工作流、发布说明）而被过度代表

## 层级分配的重要警告

层级分配反映的是**公开文档**而非私有架构中的实际情况。因此：

> **在某一层上的缺失意味着"未被公开证明"，而非"未被实现"。**

读者在解读各层覆盖密度时应始终考虑这一信息不对称。
