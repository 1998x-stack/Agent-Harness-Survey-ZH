# 02.06 纳入与排除标准

## 纳入条件（三项同时满足）

一个项目被纳入语料库，当且仅当满足以下三个条件：

1. **公开可查**：项目具有可公开访问的文档
2. **实现或规范了具体的执行环境级机制**：而非仅是概念讨论或 API 调用封装
3. **证据充分**：可用证据足以分配至少一个 ETCLOVG 层级

具体而言，以下类型的项目属于纳入范围：
- 具有可复用编排或工具路由逻辑的智能体框架
- 实例化可执行智能体环境的基准测试
- 面向智能体执行打包的沙箱
- 操作智能体状态、追踪、动作或策略的记忆、可观测性、评估或治理系统

## 排除条件

以下类型被排除：
- 简单聊天机器人演示
- 提示模板集合
- 薄模型客户端包装器
- 不携带智能体运行时的静态数据集或排行榜
- 非智能体面对的通用基础设施组件
- 无法从公开文档审查技术行为的产品页面

## 边界案例处理原则

> **按机制判定，而非按标签判定。**

仓库被命名为"智能体"不足以构成纳入理由；反之，如果一个评估或沙箱项目提供了可复用的执行环境机制，即使其标签不包含"agent"也应被纳入。
