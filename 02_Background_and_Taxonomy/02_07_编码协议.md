# 02.07 编码协议

每个保留项目依据 ETCLOVG 七层分类法进行编码，编码证据来源为公开工件本身。

## 证据来源

- README 文件
- 文档页面
- 学术论文
- 示例代码
- 发布说明
- 仓库结构（必要时）

## 多标签编码规则

由于许多系统跨越多层，编码采用**多标签**策略：

- **主层（primary layer）**：标记该工件最核心的机制所在层
- **次层（secondary layers）**：仅当文档暴露了独立的（而非附带的）能力时才分配

## 编码质量控制

当前快照采用 **单一主编码员 + 作者审计** 协议，而非正式的多编码员一致性研究，因此不报告 Cohen's kappa 或可比的标注者间统计量。

模糊案例在全量编码后进行回顾性复审，采用**保守规则**：如果公开证据未能清晰显示智能体面对的机制，则该层级分配被暂缓。
