# 05.07 上下文漂移与当前方法的局限

## 关键约束视角下的上下文漂移

从关键约束命题的视角来看，上下文漂移是一个**控制器侧的失败模式**（Bölük, 2026b）：

> 因为模型只能看到由执行环境暴露的状态投影，任务相关上下文的丢失或扭曲是**执行环境的属性**，而非仅仅是模型的属性。

## 当前方法的真实状态

前述所有技术都在不同程度、不同条件下有效。**但没有一种解决了根本问题。**

**上下文漂移（context drift）**——智能体行为在扩展交互中的渐进退化——仍然是这一层中最难解决的开放挑战。

## 症结所在

| 层面 | 问题 |
|------|------|
| **模型侧** | U 形注意力、上下文腐烂——即使模型容量足够，信息定位和使用仍不可靠 |
| **执行环境侧** | 压缩、检索、隔离各有取舍，没有统一的最优策略 |
| **系统侧** | 三层记忆的协调仍是手动的、启发式的，缺乏自动化的上下文健康监测和自适应策略选择 |

上下文漂移不是单一原因导致的问题，而是上述三个层面交互涌现的系统性故障。解决它需要模型、执行环境和编排策略的协同进化——这正是 §12 中开放问题议程的核心。
