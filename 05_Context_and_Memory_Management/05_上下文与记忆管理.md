# 05 上下文与记忆管理（C）

上下文与记忆管理层（Context and Memory Management）是提示工程、上下文工程与执行环境工程交汇的层面，也是 ETCLOVG 的第三支柱。

## 核心工程问题

一个简洁的表述足以概括：**在每个步骤给模型恰好正确的信息，不多不少。**

| 情况 | 后果 |
|------|------|
| 上下文太少 | 智能体缺乏正确行动所需的状态 |
| 上下文太多 | 性能以可测量、跨模型一致且尚未被完全理解的方式退化 |
